**Key Findings & Where Human Verification Mattered**

- **Two-Pass Verification Boosted Accuracy From ~87% to 100% on Sampled Apps:** In Pass 1, the research agent repeatedly conflated *publicly readable API documentation* with *self-serve developer access* (e.g., marking Ahrefs, Brex, Copper, Squarespace, and Grain as `self-serve` simply because their docs pages are open, even though generating an API key requires an Enterprise/paid plan or corporate onboarding). Pass 2 caught these pricing/gating traps by checking pricing pages alongside developer docs.
- **Auth Reality vs. Docs Complexity:** While **OAuth2** is supported by 52% of the 100 apps (essential for multi-tenant production apps), **Bearer tokens / Personal Access Tokens (37%)** and **API keys (24%)** are the actual first-choice auth (`auth_primary`) for rapid single-workspace prototyping.
- **Gated Categories & Outreach Priorities:** **Finance & Fintech** and **Marketing/Ads** have the highest friction (`paid` or `gated` via partner/app review—e.g., LinkedIn Ads, Google Ads Developer Token, Meta App Review, Brex, Ramp). By contrast, **Developer/Infra (100% self-serve)** and **Productivity/PM (100% self-serve)** are immediate easy wins.
- **CLI Tools vs. Hosted APIs:** Non-SaaS tools in the list like **Sherlock** and **Mermaid CLI** have no hosted REST/GraphQL API (`verdict: partial`, `blocker: no public API`)—for an agent platform like Composio, these are best packaged as sandboxed local CLI/subprocess tools rather than HTTP connectors.
- **MCP Ecosystem Momentum:** 56% of researched apps already have either an **official (34%)** or **community (22%)** MCP server, showing rapid standardization around MCP alongside traditional REST/GraphQL toolkits.
